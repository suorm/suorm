# AGENTS.md

## Core Commands
- `npm install` - Install dependencies
- `npm run dev` - Start development server (serves `suorm.js` from `/public`)
- `npm run build` - Build production assets
- `npm test` - Run all tests (requires `node` and `npm`)

## File Structure
- `/public/suorm.js` - Main JavaScript file from website
- `/README.md` - Setup instructions and contribution guide

## Workflow
1. `npm install` → 2. `npm run dev` → 3. `npm test`

## Quirks
- **Dev Server**: Serves `/public` directory directly
- **Testing**: Requires Node.js environment
- **Build**: Optimizes `suorm.js` for production
